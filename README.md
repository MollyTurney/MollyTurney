Interactive color palette generator with real-time collaboration features. Built with React, Node.js, and WebSockets for instant team synchronization.
- **Stack:** React, Express, Socket.io, PostgreSQL
- **Highlights:** Live color sharing, accessibility compliance, 1000+ daily users

### 🔐 **SecureVault CLI**
Lightweight command-line tool for encrypted secret management. Designed for developers who want security without complexity.
- **Stack:** Python, GPG encryption, SQLite
- **Highlights:** Zero-dependency installation, audit logging, 95% test coverage

- **Stack:** TypeScript, Apache Kafka, Docker, Kubernetes
- **Highlights:** Processes 10M+ events daily, sub-100ms latency, auto-scaling
